# The session decides by precedence and asks only three things; four refiners run at a time

## Intent

A refiner decides an entry's line by precedence: the human's approvals in this run, then their typed words, then the newest artifact, then what the code does today, then the archetype of the thing's kind; whatever speaks first is written `assumed`, and when the artifacts allowed alternatives, one line under `## Open` names the choice and them, so review overturns it in one click. The session asks the human only for a contradiction, for a thing no artifact and no archetype speaks to, or for a choice that would change a box they approved. A question filed under an earlier rule that this one would not ask is withdrawn by the session after it decides the box. Refiners run at most four at a time, never two siblings together, in the next command's order.

## Assumptions

- In the resume run of 2026-11-04, 18 of 29 questions offered the code's current behaviour or an existing artifact as an option, which the Guessing rule already called enough to guess, and the human spent their window on 17 answers against 4 approvals, the lever that releases drafting. The human asked for more autonomy: "A lot of the questions that I am getting are rather basic. The kind that the agent should probably decide and then leave it as assumed." The precedence extends REQ-5.5's order with the code today and the archetype; the cap of four is a first setting to tune from runs (model assumption)
