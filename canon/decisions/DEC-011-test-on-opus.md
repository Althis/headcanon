# The Valley test sessions run on Opus, not Fable

## Stated

> from now on I have downgraded the model to opus, since that is less restricted to use and less capable than Fable. If we can make it work on Opus it will be a bigger win overall for the project.

Claude Code session, 2026-10-11, at the start of the third adopt run on The Valley.

## Why [assumed]

A harness that only works on the most capable model proves little. Opus is the model most users can run, so the skills and rules are tuned against it: plain imperative steps, named decision points, no emphatic directives that Opus is known to over-trigger on, and nothing left to judgment that the skill can decide. Fable remains the model for building HeadCanon itself in this session.
