# User journeys are intent records, not tests, kept separate from the tree

## Stated

> User journeys are intent records, not tests, kept separate from the tree

Source: docs/design-brief-v0.md:65

## Intent [assumed]

A journey says what a user does and sees, step by step, and stays an intent record. An end-to-end test is written from a journey and names it, with the tool the product's platform calls for; the journey is recorded first, guessed or approved, where the user reads it on the Journeys page (DEC-026).
