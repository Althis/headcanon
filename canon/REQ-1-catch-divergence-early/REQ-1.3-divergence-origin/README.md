# Tag each caught divergence with its origin, as an opt-out field; trial it on the pet project and remove it if useless

## Stated

> Tag each caught divergence with its origin, as an opt-out field; trial it on the pet project and remove it if useless

Source: docs/design-brief-v0.md:55

## Intent [assumed]

Each caught divergence is tagged with one of three origins: a misread request, a hidden obstacle, or a side effect. Real usage then shows which hypothesis dominates.
