# Root cause stays an open hypothesis; the design must work under both

## Stated

> Root cause stays an open hypothesis; the design must work under both

Source: docs/design-brief-v0.md:54

## Intent [assumed]

Hypothesis A: the agent finds the request infeasible mid-work and has no sanctioned way to say so. Hypothesis B: it misreads the request and is not trained to doubt itself. Nothing in the design may depend on one being true.
