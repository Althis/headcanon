# Writ verifies every change against the canon

## Stated

> Writ verifies every commit, PR or release against the canon, using the team's existing test tools rather than replacing them (decided).

Source: docs/design-brief-v0.md:330

## Intent [assumed]

Three checks: no earlier goal was overwritten, everything new is documented in the canon, and the documentation does not contradict itself.
