# Decision records link to intents and get flagged when an intent changes

## Stated

> Decision records link to intents and get flagged when an intent changes

Source: docs/design-brief-v0.md:80

## Intent [assumed]

Decision records capture short-term implementation choices, each linked to the intent it serves. When an intent changes, its linked decisions are flagged for review. This is where the agent questions its own earlier choices.
