# Resolved only on the human's explicit agreement; tacit approval never counts

## Stated

> Resolved only on the human's explicit agreement; tacit approval never counts

Source: docs/design-brief-v0.md:72

## Intent [assumed]

An item becomes resolved only when the human explicitly says something that means agreement. Tacit approval never counts. The agent decides which mode applies from the conversation.
