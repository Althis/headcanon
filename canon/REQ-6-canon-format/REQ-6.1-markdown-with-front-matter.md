# Canon stored as Markdown with front-matter, in a folder tree mirroring the requirement tree

## Stated

> Canon stored as Markdown with front-matter, in a folder tree mirroring the requirement tree

Source: docs/design-brief-v0.md:73

## Intent [assumed]

Front-matter holds each node's ID, certainty state, file links and baselines; the body holds the human-readable intent. Editors show the tree in their file explorer, GitHub shows each folder's README, and every intent change is a readable Markdown diff.
