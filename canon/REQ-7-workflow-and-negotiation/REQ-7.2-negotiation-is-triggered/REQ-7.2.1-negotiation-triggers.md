# Negotiation triggers

## Proposed in brief

> - An obstacle the agent can't get around without changing intent.
> - An assumed item becoming decisive for the next step.
> - Two intents contradicting each other.
> - The agent being unable to write a binary test for a leaf. This is often the earliest sign it doesn't understand what's wanted.

Source: docs/design-brief-v0.md:267-272

## Intent

Four triggers: an obstacle that cannot be passed without changing intent; an assumed item becoming decisive; two intents contradicting; and the agent being unable to write a binary test for a leaf, often the earliest sign it does not understand what is wanted.
