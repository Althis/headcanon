# Workflow runs requirements → tests → implementation

## Stated

> Workflow runs requirements → tests → implementation

Source: docs/design-brief-v0.md:64

## Intent [assumed]

1. Refine requirements until the part being built has binary leaves. 2. Derive tests from those leaves and journeys. 3. Implement against the tests. 4. Report against the intents: verified, assumed, untested.
