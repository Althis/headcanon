# Brand

Working files for the HeadCanon identity.

- `colour.md`: the colour schemes, how they were chosen, the values and the
  rules of use.
- `logos.html`: the review sheet. Open it in a browser; the buttons switch
  between the three colour schemes and between light and dark. Every candidate
  is shown as a lockup, at 64, 32 and 16px, in one colour, on ink, and in a
  mock of the viewer header beside the certainty states.
- `logos/`: one folder of SVGs per candidate, in scheme A:
  `NN-name-mark.svg` (64x64 mark), `NN-name-lockup.svg` (mark and wordmark,
  transparent) and `NN-name-lockup-dark.svg` (on ink).
- `tools/build-logos.js`: generates all of the above. It needs IBM Plex Sans
  as TTF files, which it does not ship; see the header of the script.

The eight candidates:

| # | Name | Idea |
| --- | --- | --- |
| 01 | Held canon | A head with the canon tree inside, the root lit |
| 02 | HC rung | Monogram: the H's rung runs on into the C |
| 03 | Fork | The Tree view: one root box, a bus, three children |
| 04 | Quote root | The stated quote is the root; the tree grows from it |
| 05 | C ring | An open ring around a point: C, head, reticle |
| 06 | Profile line | One stroke: a profile that turns inward and forks |
| 07 | h tree | A lowercase h whose stem sprouts a branch |
| 08 | Thought box | A thought bubble whose cloud is a canon card |

Chosen on 2026-10-29: candidate 01 Held canon in scheme A, Ink & Verdigris.

- `final/`: the chosen mark as deliverables. `headcanon-mark.svg` and `-dark`
  (64x64), `headcanon-mark-mono.svg` (currentColor), `headcanon-lockup.svg`
  and `-dark`, `favicon.svg` (a coarser tree that holds at 16px, switches
  with the browser theme), PNGs at 16, 32, 180, 192, 512 and 1024, and
  `social-preview.png` (1280x640, for the GitHub repository settings and the
  site's Open Graph tag). Regenerated by `tools/final-assets.js`.
- The other seven candidates stay in `logos/` for the record.
